## 先分清楚：共享主機、VPS、雲端主機差在哪？

三者的差別集中在三件事：資源怎麼分、誰負責維護、能不能彈性擴充。共享主機像合租公寓，一台伺服器塞了很多用戶，隔壁網站流量爆了你也會跟著卡；VPS 是把一台實體機切成幾個資源獨立的小機器，你拿到完整控制權，但環境、安全、備份都自己來；雲端主機則按用量計費、彈性最高，價格也最貴，比較適合已經有穩定流量和 IT 能力的團隊。

| 類型 | 資源 | 適合對象 | 價格帶 |
| --- | --- | --- | --- |
| 共享主機 | 與多人共用 | 個人部落格、形象網站 | 每月約 US$3–10 |
| VPS | 獨立分配 | 想要控制權、有多站需求 | 年付促銷常見 US$10–40/年 |
| 雲端主機 | 彈性調度 | 高流量網站、企業站 | 依用量計費 |

很多比較文直接跳進品牌排名，但選錯類型比選錯品牌更傷：新手買了 VPS 可能一個月都還沒把 WordPress 跑起來，老手用共享主機則會被資源限制綁手綁腳。

## 用 RackNerd 架 WordPress：實際流程和幾個容易踩的坑

整體流程一個下午可以走完：選機房、裝系統、跑一鍵腳本或面板、綁網域、裝 SSL。容易出問題的通常是機房選擇、資源預算和備份習慣這三件事。

基本步驟：

1. 開通 VPS 時選機房和作業系統，一般選 Ubuntu 或 Debian 的範本。
2. 用一鍵安裝腳本，或裝 aaPanel 這類免費面板來部署網站環境。
3. 安裝 WordPress，申請 Let's Encrypt 免費 SSL 憑證。
4. 自己排備份——VPS 不會自動幫你備網站，把備份檔定期丟到主機以外的空間是基本紀律。

三個坑值得先說：

- **機房與延遲**：RackNerd 沒有亞洲機房，美西到台灣的延遲明顯高於新加坡機房的託管型主機。做給歐美用戶看的外貿站、聯盟站影響不大；受眾以台灣為主的話，前面套一層 CDN 可以補掉不少差距，但如果你完全不想碰這些，這點就夠勸退了。
- **資源預算**：1GB 記憶體跑 WordPress 沒問題，前提是別裝 Bridge、Avada 這種腫瘤主題，也別把 Elementor 延伸外掛整包灌進去——這類組合在共享主機上是變慢，在 1GB VPS 上是直接把記憶體吃光。記得設定 swap 給系統留緩衝。
- **預付金額**：促銷多為年付，先買一年試水溫就好，別一上來就鎖多年。

## WordPress 主機比較常見問題

### RackNerd 的 VPS 可以架幾個 WordPress 網站？

沒有站數上限，瓶頸是資源。1GB 方案跑一到三個輕量站（形象站、文字為主的部落格）是合理範圍；要跑 WooCommerce 或多語系網站，就往 2.5GB 以上的檔位看。

### 便宜 VPS 穩不穩？會不會跑路？

KVM 架構下資源獨立，穩定性比同價位共享主機有結構上的優勢；RackNerd 也已營運數年，在主機社群的討論度一直不低。但用便宜 VPS 的基本共識是自己做好備份，不要把唯一一份網站資料放在上面——這條紀律跟品牌無關。

### 年付是不是綁約？

年付是預付一年，不是合約綁定；到期不續約，機器到期就停止。預算緊的話，先用 1GB 一年檔試一段時間再決定升級，是最省事的節奏。

### 完全新手該從共享主機還是 VPS 開始？

除非你本來就想順便學伺服器管理，否則從託管型共享主機開始。先把 WordPress 本身玩熟，等網站有流量、有收入，再考慮搬到 VPS，搬家的時候檔案和資料庫都備好就行。
